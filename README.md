# Vending Machine

Симулятор вендинговых аппаратов. Первая версия, сделанная за выходные по [техническому заданию](description.md), лежит в ветке `v1`. Вторая выросла из нее: аппарат больше не знает заранее, чем торгует. Ассортимент, ячейки, монеты, валюта, цены и правила продажи задаются в конфигурации, а владелец меняет их на ходу.

- Несколько аппаратов у разных владельцев, у каждого свои товары, касса и правила.
- Несколько покупателей со своими кошельками. Пока один внес деньги, аппарат занят для остальных. Если покупатель ушел, внесенная сумма через таймаут возвращается ему же.
- Правила цены: счастливые часы, каждый N-й товар бесплатно, ночная наценка. Ограничения: часы работы, лимит покупок в день, товары 18+ после подтверждения возраста.
- Касса: лимит сдачи, режим "только без сдачи", когда кончается мелочь, инкассация с остатком монет на сдачу. Сдача подбирается наименьшим числом монет с учетом того, что есть в кассе.
- Веб и консоль работают с одним и тем же состоянием: можно купить кофе в браузере и увидеть продажу в отчете из консоли.

Нужен PHP 7.1+ с расширениями json и mbstring, без зависимостей. Под капотом свой мини-фреймворк: автозагрузка PSR-4, контейнер с автосборкой через Reflection, роутер с параметрами, CSRF, шаблоны с макетами, JSON-хранилище с блокировкой файла, консольные команды.

## Запуск в браузере

```bash
php -S localhost:8000 index.php
```

Открыть http://localhost:8000. Каждый посетитель становится гостем со своим кошельком, в шапке можно переключиться на Ивана, Марию или Петра и проверить, как аппарат ведет себя с двумя покупателями.

Панель владельца: http://localhost:8000/operator/login

| Логин            | Пароль       | Аппараты                   |
|------------------|--------------|----------------------------|
| `coffee-service` | `coffee2020` | кофейный автомат           |
| `snack-market`   | `snack2020`  | снеки, аппарат в аэропорту |

## Запуск в консоли

```bash
php bin/vending                          # список команд
php bin/vending machines
php bin/vending status --machine=snacks
php bin/vending insert 10 10 --as=maria  # Мария вносит 20 руб. в кофейный автомат
php bin/vending buy A2 --as=maria
php bin/vending buy B3 --machine=snacks --confirm-age
php bin/vending machine:restock A1 --machine=coffee
php bin/vending machine:report --days
php bin/vending shell --as=petr          # интерактивный режим
```

Без `--as` и `--machine` консоль работает за Ивана у кофейного автомата, это настраивается в `config.php`. Команды `machine:*` - обслуживание аппарата, в консоли они доступны без пароля, как у техника с ключом от аппарата.

## Конфигурация аппарата

Аппараты лежат в `data/machines/*.json`. Все суммы - целые числа в копейках или центах:

```json
{
  "id": "coffee",
  "name": "Кофейный автомат",
  "operator": "coffee-service",
  "occupancy_timeout": 120,
  "currency": {"code": "RUB", "symbol": "руб.", "digits": 2},
  "cash": {"coins": {"100": 100, "1000": 100}, "max_change": 10000, "reserve": 10, "keep": 30},
  "catalog": [{"sku": "coffee", "name": "Кофе", "category": "hot", "price": 1800}],
  "slots": [{"code": "A2", "capacity": 30, "sku": "coffee", "quantity": 20}],
  "rules": [{"id": "morning", "type": "happy_hours", "label": "Утром -20%", "from": "08:00", "to": "10:00", "percent": 20, "category": "hot"}]
}
```

- `cash.coins` - какие монеты принимает аппарат и сколько их в кассе. `max_change` - самая большая сдача. `reserve` - если монет какого-то номинала, кроме самого крупного, меньше, аппарат продает только без сдачи. `keep` - сколько монет оставить при инкассации.
- `slots` - ячейки витрины. В каталоге могут быть товары, которых сейчас нет в ячейках: владелец загружает их из панели.

Типы правил:

| type             | Параметры                           | Что делает                                              |
|------------------|-------------------------------------|---------------------------------------------------------|
| `happy_hours`    | `from`, `to`, `percent`, `category` | скидка в часы, можно только на категорию                |
| `every_nth_free` | `sku`, `every`                      | каждый N-й такой товар бесплатно                        |
| `night_markup`   | `from`, `to`, `percent`             | наценка в часы, интервал может идти через полночь       |
| `working_hours`  | `from`, `to`                        | вне этих часов аппарат не продает                       |
| `purchase_limit` | `per_day`                           | не больше N покупок в день на покупателя                |
| `age_check`      |                                     | товары с `"adult": true` только после подтверждения 18+ |

Правила цены применяются по порядку, итог округляется вверх до самой мелкой монеты аппарата. Новое правило - класс с интерфейсом `PriceRule` или `Restriction` и строка в `RuleFactory`.

Покупатели с кошельками - `data/customers.json`, кошелек нового гостя - `data/wallet.json`, владельцы - `data/operators.json`. Текущее состояние всех аппаратов пишется в `storage/state.json`, `php bin/vending reset` возвращает все к начальным данным.

## Как устроено

```
src/Framework/       мини-фреймворк
src/Vending/         аппарат без привязки к вебу и консоли
  Money/             валюта, монеты, касса, подбор сдачи
  Catalog/           товары и ячейки
  Rules/             правила цены и ограничения продажи
  Sales/             журнал продаж и отчеты
src/App/             контроллеры и консольные команды
templates/, assets/  страницы, стили и скрипты
data/                начальные данные
tests/               тесты на деньги, правила и очередь у аппарата
```
